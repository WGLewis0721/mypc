# mypc

**Demo / POC.** This is a concept website build, not a real business. Any business facts on
the site (services, pricing, copy) are illustrative placeholders. The deployed site carries a
visible demo notice on every page.

## Stack

- **Wix Headless Fast**, Wix-hosted (managed Astro frontend on Wix's shipped `@wix/sdk` code).
- Frontend source, brief, and assets live in this repo. The live site is published with
  `wix release` — there is no GitHub→Wix auto-deploy.
